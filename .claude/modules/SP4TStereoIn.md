# SP4TStereoIn Module

## Description

A basic Ambisonic encoder for mono or stereo input signals.

The module takes an input mono or stereo signal and converts it into an Ambisonic signal. The source can be located in the 3D space (panner) via the "azimuth" and "elevation" angles. The source is either mono if only the left input jack is connected or stereo if both left and right input jacks are connected. For an input stereo signal, the "spread" angle controls the angular distance between the "mono" direction (as determined by the azimuth and elevation angles) and each of the left and right actual sources.

## Specifications

- Width: 6 HP
- 3 Knobs
  - azimuth (-180 to 180 degrees, default 0 degrees)
  - elevation (-180 to 180 degrees, default 0 degrees)
  - spread (0 to 90 degrees, default 45 degrees)
- 3 CV jack inputs:
  - azimuth (bipolar)
  - elevation (bipolar)
  - spread (bipolar)
- 2 audio jack inputs:
  - Left (Mono)
  - Right
- 1 Ambisonic jack output (polyphonic)
